Study Notes

  • CPU: The central processing unit executes program instructions and processes data.
  • Volatile memory: RAM only keeps data while the computer has power; its contents are lost when it turns off.
  • CPU cache: Small, high-speed memory that stores frequently used data so the CPU can access it faster.
